Outlook Web Access

Open a full Outlook interface in a new tab using a captured token.

Method 1: Refresh Token & Open Outlook

Refreshes your token for Graph API access, then opens the Outlook portal in a new tab.

Method 2: Use Existing Access Token

Pick an access token that's already scoped for https://graph.microsoft.com and open Outlook directly.

Tip: Both methods open the Outlook portal at /owa in a new tab. You can also use Outlook (Graph) for an inline view within this dashboard.
